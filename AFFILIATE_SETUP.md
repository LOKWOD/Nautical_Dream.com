# Nautical Dream affiliate setup

Nautical Dream's publication pipeline converts eligible commercial buttons in buyer guides into tracked affiliate links during the GitHub Pages build. It also adds disclosures, compliant link attributes, click analytics and a machine-readable report.

## Current live configuration

Amazon Associates is enabled in `affiliate-config.json` with the US tracking ID `nauticaldr087-20`. A repository variable named `AMAZON_ASSOCIATE_TAG`, when present, takes priority over the value in the config file.

Eligible pages currently include:

- `best-*.html` buyer guides
- `*-guide.html` articles with commercial buttons
- `beginner-boat-diy*.html`

This includes the seasonal commerce pages added August 18, 2026:

- `best-boat-winterization-gear.html`
- `best-boat-trailer-accessories.html`
- `snowbird-boat-trailering-guide.html`

The seasonal pages are also injected into the deployed `sitemap.xml` by `scripts/inject-commerce-sitemap.mjs` before validation and publication.

## How conversion works

The source HTML keeps a safe manufacturer destination on each approved shopping-style button. During build, `scripts/inject-affiliate-links.mjs`:

1. Finds eligible external product buttons.
2. Derives a stable product key from the page and nearest product heading.
3. Uses a direct affiliate override when one exists.
4. Otherwise generates an Amazon product-search URL with the configured Associate tag.
5. Changes the visible CTA to `Check current price`.
6. Adds `rel="sponsored nofollow noopener noreferrer"`.
7. Adds the affiliate disclosure, including Amazon's required Associate statement when Amazon links are present.
8. Installs click tracking and writes `assets/affiliate-link-report.json`.

The deployment fails if an Amazon tag is configured but no eligible commercial links are converted, which prevents a silent "looks monetized but earns nothing" failure.

## Direct affiliate programs

Direct retailer deep links take priority over Amazon. To add West Marine, Defender, Impact partners or another approved affiliate program, generate the complete tracked HTTPS deep link in that program's portal and add it to the `overrides` array in `affiliate-config.json`.

Example:

```json
{
  "key": "best-chartplotters.html::garmin-echomap-uhd2-7-or-9-inch",
  "url": "PASTE_THE_COMPLETE_TRACKED_HTTPS_DEEP_LINK_HERE",
  "retailer": "West Marine",
  "label": "Check West Marine price"
}
```

Use the exact key from `assets/affiliate-link-report.json`. An override can also use `matchUrl` when every occurrence of one manufacturer URL should map to the same approved affiliate destination.

Never paste an ordinary retailer URL and label it affiliate. Only links generated by an approved affiliate account should be configured as direct commission links.

## Publication order

Both the Pages deployment and the pull-request audit run the publication pipeline in this order:

1. Build authority pages.
2. Generate expansion pages.
3. Inject seasonal commerce URLs into the sitemap.
4. Inject Impact verification.
5. Inject affiliate links and disclosures.
6. Inject Cloudflare analytics.
7. Validate the final static site.

The Pages workflow additionally installs the visitor beacon before the final audit and deployment.

## Verification

A successful build writes `assets/affiliate-link-report.json` with totals for eligible pages, commercial links, active affiliate links, direct affiliate links and Amazon affiliate links.

Useful local checks:

```bash
node scripts/inject-commerce-sitemap.mjs
node scripts/inject-affiliate-links.mjs
node scripts/audit-static-site.mjs
```

For the deployed site, verify several `Check current price` buttons resolve to Amazon URLs containing the active tracking ID and use Amazon Associates' own Link Checker/dashboard to confirm tracking.

## Important Amazon rule

Do not purchase through your own Amazon affiliate links or ask relatives, employees or close associates to do so. Use the Associates dashboard and Link Checker for validation instead.
