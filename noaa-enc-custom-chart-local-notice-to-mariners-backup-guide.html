NOAA ENC and Custom Charts: Build an Updated Navigation Backup Without Trusting a Screenshot

A chart image is only useful when you can name its official source, edition state, update check and offline limits. Build a small evidence trail before the boat loses coverage.

Downloading a map is not the same as maintaining a navigation backup. The backup needs a traceable official source, a recorded update check, an offline test and a clear boundary: it supports, but does not replace, observation, soundings, weather awareness, local knowledge, Notices to Mariners or the primary navigation system.

Start with the current official product family

NOAA identifies the Electronic Navigational Chart as its primary chart product and says traditional NOAA paper nautical charts are no longer produced. ENCs are vector datasets intended for electronic systems that support them. NOAA Custom Chart is a separate web tool that renders a user-defined static chart from current ENC data for printing or PDF use.

Begin at NOAA’s chart portal, not a search-result image, old PDF or forum attachment. Select the actual waterway and scale needed, then preserve the official download page and date. A phone screenshot has no reliable edition state, scale behavior or update trail.

Download the ENC set from NOAA and preserve provenance

Use the NOAA chart locator or download service to identify cells that cover the route and meaningful alternatives. NOAA says ENC files are updated every weekday evening, but that does not mean a stored copy updates itself. Record when each file was obtained and how it reaches the chartplotter or app.

Follow the electronics or software maker’s installation and compatibility instructions. Do not rename, edit or convert data unless the supported workflow calls for it. A file that exists on a laptop is not a functioning backup until it opens on the intended device without a network.

Create a Custom Chart without pretending it is a traditional chart

NOAA Custom Chart lets a user choose an extent and scale and generate a static output from current ENC data. NOAA explains that these charts do not have traditional chart numbers. Name the output by route, extent and creation date rather than inventing a chart number.

Save the tool’s GeoJSON catalog when available so the setup can be reopened and regenerated. Inspect the output at its intended print size: labels, features and symbols can change with scale. A page printed “fit to paper” without checking scale is not equivalent to the designed output.

Add Coast Pilot and NOAA Navigation Updates

Charted features do not contain every operational detail. NOAA’s recreational-boater resources connect users to Coast Pilot, chart products, tides, currents and weather. Open the relevant Coast Pilot volume and its current update material for route descriptions, regulations, hazards and facilities that belong in narrative form.

Use NOAA Navigation Updates to search recent corrections affecting the route. Record the search date, waterway and result. Do not copy one correction onto a chart and assume the rest of the source set is current; the source-control card should show each product independently.

Check the weekly Local Notice to Mariners

The Coast Guard says Local Notices to Mariners are published weekly. Its harmonized system references waterways by name and latitude/longitude rather than relying only on traditional chart numbers. Search the relevant Coast Guard district notice using the official waterway name, nearby aids, bridges, locks and coordinates.

Look for relocated or extinguished aids, dredging, construction, events, safety zones, channel changes and temporary restrictions. Read the notice and its effective dates. An expired project notice should not be carried forward; a future restriction should not be treated as active early.

Test the backup offline and away from the dock

Place the device in airplane mode or otherwise remove network access. Open the chart, zoom through the route, display position if the device supports offline GNSS, and confirm the relevant notes and PDFs are actually stored. Reboot the device and repeat. Test power cables and a protected spare power source.

The navigation-app failure drill provides a crew exercise. Pair it with marine electronics basics and the device maker’s manual. An offline map that opens only from a recent-app cache is not a dependable backup.

Separate chart currency from weather and real-time observation

An updated chart does not show today’s thunderstorm, current water level, floating debris, traffic, visibility or a buoy that has just moved. Check current NOAA weather, tides or currents as appropriate and observe the water continuously. Use depth sounder, radar, visual bearings and local information according to the boat and conditions.

The weather hub, thunderstorm planning guide and wind, waves and fetch guide address separate decisions. Never make a static paper output carry a job it cannot do.

Use a predeparture update sequence

  1. Confirm the route and alternates.
  2. Open the official NOAA chart portal and verify required ENC cells.
  3. Update the primary chart system using its supported process.
  4. Regenerate or inspect the Custom Chart output.
  5. Check Coast Pilot and NOAA Navigation Updates.
  6. Read the latest applicable Local Notice to Mariners.
  7. Check weather, tides, currents and local operating information.
  8. Test the offline device and printed material.
  9. Brief the crew on the primary and backup tools.
  10. Record the completed checks on the source-control card.

Repeat the sequence whenever the trip changes or the stored package becomes stale. The card is not a certificate of safety; it is evidence that the operator completed identifiable checks.

Know the limits and when to seek instruction

Do not use this guide to determine legal chart-carriage requirements, certify an electronic installation, choose a route through unfamiliar restricted water or interpret a symbol you do not understand. Consult the Coast Guard, controlling waterway authority, current regulations, the chart-system maker or a qualified navigation instructor.

Reject unofficial chart bundles with no update history, screenshots without scale or source, and route exports that cannot be inspected offline. Frequently asked questions

Is NOAA Custom Chart the same as a traditional NOAA paper chart?

No. NOAA Custom Chart creates a static output from current ENC data and NOAA says it does not use traditional chart numbers.

How often are NOAA ENC files updated?

NOAA says ENC files are updated every weekday evening. A stored copy or third-party system still needs its supported update process.

Is a current chart enough for departure?

No. Check applicable Coast Pilot information, Navigation Updates, Local Notices to Mariners, weather, tides or currents, local rules and real-time conditions.
